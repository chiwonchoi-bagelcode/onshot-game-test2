# 와장창 냥이 🐾 — 고양이의 완전범죄

세로형 모바일 3D 물리 장난 게임. 손가락 하나로 물건을 툭 쳐서 연쇄 사고를 일으키고, 집사가 돌아오면 아무 일 없었다는 듯 시치미를 뗍니다.

- **조작**: 물건을 누른 채 보내고 싶은 방향으로 끌었다 놓기. 끈 길이 = 힘, 누른 높이 = 치는 위치(위를 치면 잘 넘어지고 아래를 치면 미끄러짐).
- **제한된 앞발**: 방마다 2~3번의 장난. 목표를 망가뜨리면 성공, 피해액(점수)으로 별 1~3개.
- **연쇄**: 한 번의 장난 이후 일어나는 모든 파손·추락·넘어짐이 연쇄로 이어지고, 길수록 보너스가 붙습니다.
- **시치미**: 목표를 달성하면 남은 앞발로 더 어지르거나 "시치미 떼기"로 끝낼 수 있어요(남은 앞발 보너스).

## 방과 장난 (3개 방 × 3가지 상황)

| | 상황 | 직접 해결 | 간접/연쇄 해결 |
|---|---|---|---|
| 1-1 | 첫 번째 장난 (꽃병) | 꽃병을 탁자 밖으로 | 책 도미노 → 꽃병 → 바닥 찻잔 세트 |
| 1-2 | TV 대참사 | 무거운 TV를 꼭대기에서 세게 | 스탠드 조명/탄산 로켓 → 벽 선반 붕괴 → TV |
| 1-3 | 책장 꼭대기의 보물 (손이 안 닿음) | 책장 위를 쳐서 흔들기 | 흔들릴 때 한 번 더 → 책장 전체가 쓰러져 탁자까지 |
| 2-1 | 식탁보의 마술 | 접시를 하나씩(부족!) | 식탁보 살살 당기기 = 전부 와장창 / 확 잡아빼기 = 마술(실패) |
| 2-2 | 높은 선반 작전 (손이 안 닿음) | — | 토스터를 선반 밑으로 밀기 → 빵이 튀어 선반 강타 / 탄산 로켓 |
| 2-3 | 달걀 대소동 | 달걀판 떨어뜨리기 | 밀대 굴려 식탁 달걀 한 번에 쓸기 |
| 3-1 | 새벽 5시 모닝콜 | 자명종 떨어뜨리기(혼자선 부족) | 선반 물건 낙하, 깨지는 소리, 고무오리… 잠 게이지 채우기 |
| 3-2 | 마감 직전 노트북 | 노트북을 옆으로 밀기 | 스탠드로 책상 쓸기, 책 더미 치우기 |
| 3-3 | 완전 범죄 (피해액 목표) | 개별 파괴로는 부족 | 도미노 → 탄산 로켓 발사 → 책상 위 선반 붕괴 → 노트북 |

물건 반응: 도자기·유리 산산조각, 물/커피/주스 웅덩이, 흙·밀가루 구름, 달걀 노른자, 동전·구슬 쏟아짐, TV·노트북 스파크, 로봇청소기(켜면 알아서 돌아다님), 흔든 탄산음료(대각선 로켓), 토스터(지연 팝업), 자명종(떨어지면 울리며 집사를 깨움), 털실(굴러간 자리에 실 자국), 고무오리(삑), 바퀴 의자, 벽 선반(충격받으면 무너짐) 등.

## 실행

```bash
npm install
npm run dev            # http://localhost:5173 (휴대폰은 같은 네트워크에서 --host 주소로 접속)
npm run build          # dist/ 정적 빌드
npm run build:single   # dist-single/index.html 한 파일짜리 빌드(어디든 올리기 쉬움)
```

## 구조

- `src/game/` — 규칙(`Game.ts`: 고정 스텝 물리, 충격 판정, 점수·연쇄·목표·종료 흐름), `Prop`, `catalog.ts`(모든 소품), `specials.ts`(로봇청소기·로켓·식탁보·토스터·자명종·털실), `Cat.ts`, `Owner.ts`, `Input.ts`(한 손가락 조작), `Aim.ts`
- `src/levels/` — 방 디오라마(`rooms.ts`)와 레벨 정의(`levels.ts`)
- `src/render/` — 카메라 자동 프레이밍/흔들림/적응형 해상도(`Stage.ts`), 로우폴리 키트, 드로우콜 병합
- `src/fx/` — 물리 파편(인스턴싱), 파티클, 얼룩 데칼
- `src/audio/` — WebAudio로 합성한 효과음·고양이 울음·배경음악(에셋 파일 없음)
- `tools/sim.ts` — 브라우저 없이 실제 게임 로직으로 레벨을 시뮬레이션해 공략을 검증

```bash
npx tsx tools/sim.ts props A1                                   # 시작 상태 점검
npx tsx tools/sim.ts plan A1 '[{"pick":"book","near":[-1.05,1.5,0.55],"dir":[1,0],"power":0.5,"at":"top"}]'
npx tsx tools/sim.ts explore C3 50                              # 무작위 플레이 승률/점수 분포
```

기술: TypeScript, Three.js(렌더링), Rapier(WASM 물리), Vite.
